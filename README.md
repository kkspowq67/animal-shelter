# Приют для животных "Верный друг"

Веб-приложение для приюта животных. Позволяет просматривать карточки питомцев, фильтровать их, оставлять заявки на усыновление и играть в симулятор приюта.

## Стек технологий
- **Фронтенд:** React, Vite, Swiper, Framer Motion
- **Бэкенд:** Node.js, Express
- **База данных:** SQLite, Prisma ORM
- **Стили:** CSS

## Функционал
- Слайдер с питомцами (данные из БД)
- Таблица питомцев с поиском и фильтрами
- Анимации при скролле
- API для получения списка питомцев и отправки заявок
- 🎮 Симулятор приюта: выбор питомца, анкета, перетаскивание питомца к хозяину

## Запуск проекта

### Бэкенд
cd backend
npm install
npx prisma migrate dev
node prisma/seed.js
npx nodemon src/index.js

### Фронтенд
cd frontend
npm install
npm run dev

После запуска открой: http://localhost:5173

### Симулятор приюта
Игра доступна по адресу: http://localhost:5173/shelter-game/shelter-game.html
Или нажми кнопку «🎮 Выберите питомца» на главной странице сайта.
